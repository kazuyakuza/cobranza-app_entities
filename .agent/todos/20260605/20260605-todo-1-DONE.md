# TODO - Encryption & Data Model Improvements

**Goal**: Add proper encryption for sensitive data + improve Address structure.

**Encryption behaviour/process overview**:

- properties that need encryption are JSONB with encryptedData, encryptedKeyName values
- encrypted properties that need to be indexed, has a extra property (not inside the jsonb) with a hash value of the data
- 1st microservice that receives data that need to be encrypted, encrypts it
- encryption and hash keys are stored in the microservice .env
- encrypted data navigates encrypted between microservices, and only the ones with the encryption keys can decrypt them
