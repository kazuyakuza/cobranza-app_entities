## 2. JSON Schema Generation

For each entity, generate a corresponding JSON Schema file, like:

```json
// debt.schema.json
{
  "$schema": "http://json-schema.org/draft-07/schema#",
  "title": "Debt",
  "type": "object",
  "properties": {
    "id": { "type": "string", "format": "uuid" },
    "companyId": { "type": "string", "format": "uuid" },
    "totalAmount": { "type": "number" },
    ...
  },
  "required": ["companyId", "clientId", "totalAmount", ...]
}
```
