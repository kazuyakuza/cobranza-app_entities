### Issue 2 — `@IsDateString()` applied to `Date`-typed properties in §6

- **Location**: `docs/usage-angular.md`, lines 306–310.
- **Problem**: `CreateDebtForm` implements `ApiCreateDebtDto`, whose `dueDate` and `issueDate` are `Date`. The snippet decorates them with `@IsDateString()`, which validates ISO-8601 **strings**, not `Date` instances. Additionally, `plainToInstance` will not auto-convert strings to `Date` without `@Type(() => Date)`.
- **Fix**: Replace `@IsDateString()` with `@Type(() => Date)` + `@IsDate()` for both `dueDate` and `issueDate`, and add `import { Type } from 'class-transformer';` to the `CreateDebtForm` snippet. This preserves the `implements ApiCreateDebtDto` compile-time guarantee.
