# Plan: Task 1 — Configure ESLint + Prettier

## Overview
Install and configure ESLint v8 with TypeScript support and Prettier for a TypeScript-only library project. The project uses TypeScript 5.x, targets ES2022 modules, and keeps source code in `src/`.

## Analysis
- `package.json` exists with `typescript@^5.4.0` and `@types/node@^20`.
- `tsconfig.json` sets `target: "ES2022"`, `module: "ES2022"`, `rootDir: "./src"`.
- `"type": "module"` is **not** present in `package.json`; therefore config files should use CommonJS/JSON where possible to avoid ESM/CJS friction.
- Existing code style in `src/` uses semicolons, single quotes, 2-space indentation, and trailing commas.

## Steps

### 1. Install Dev Dependencies

Run the following command in the project root:

```bash
npm install --save-dev \
  eslint@^8.57.0 \
  @typescript-eslint/parser@^7.18.0 \
  @typescript-eslint/eslint-plugin@^7.18.0 \
  prettier@^3.3.0 \
  eslint-config-prettier@^9.1.0
```

> `eslint-plugin-prettier` is intentionally omitted. Prettier will run standalone via npm scripts for separation of concerns and faster linting.

### 2. Create `.eslintrc.json`

Create file `C:\projects\cobranza-app\entities\.eslintrc.json` with the exact content:

```json
{
  "root": true,
  "env": {
    "node": true,
    "es2022": true
  },
  "parser": "@typescript-eslint/parser",
  "parserOptions": {
    "project": "./tsconfig.json",
    "sourceType": "module",
    "ecmaVersion": 2022
  },
  "plugins": ["@typescript-eslint"],
  "extends": [
    "eslint:recommended",
    "plugin:@typescript-eslint/recommended",
    "plugin:@typescript-eslint/recommended-requiring-type-checking",
    "prettier"
  ],
  "ignorePatterns": ["dist", "node_modules", ".eslintrc.json"],
  "rules": {}
}
```

### 3. Create `.prettierrc`

Create file `C:\projects\cobranza-app\entities\.prettierrc` with the exact content:

```json
{
  "semi": true,
  "singleQuote": true,
  "tabWidth": 2,
  "trailingComma": "all",
  "printWidth": 100,
  "endOfLine": "lf"
}
```

### 4. Create `.eslintignore`

Create file `C:\projects\cobranza-app\entities\.eslintignore` with the exact content:

```text
dist
node_modules
```

### 5. Create `.prettierignore`

Create file `C:\projects\cobranza-app\entities\.prettierignore` with the exact content:

```text
dist
node_modules
package-lock.json
```

### 6. Update `package.json` Scripts

Edit `C:\projects\cobranza-app\entities\package.json` to add the following entries inside the `"scripts"` object, preserving existing scripts (`build`, `clean`, `typecheck`, `prepublishOnly`):

```json
    "lint": "eslint src --ext .ts",
    "lint:fix": "eslint src --ext .ts --fix",
    "format": "prettier --write \"src/**/*.ts\"",
    "format:check": "prettier --check \"src/**/*.ts\""
```

### 7. Update `.gitignore`

Edit `C:\projects\cobranza-app\entities\.gitignore` to append `.eslintcache` so it is not tracked:

```text
.eslintcache
```

### 8. Verification Commands

After all files are created and dependencies installed, the implementer must run:

```bash
npm run lint
npm run format:check
```

- `npm run lint` must exit `0` with no errors.
- `npm run format:check` must exit `0` if all files already match Prettier rules; if not, `npm run format` must be executed to normalize existing files.
